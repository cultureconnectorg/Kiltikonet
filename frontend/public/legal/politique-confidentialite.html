Politique de Confidentialité

Dernière mise à jour : 28 février 2026

Résumé : Nous collectons uniquement les données nécessaires à votre accréditation et au bon fonctionnement de l'événement Culture Connect 2026. Vos données ne sont jamais vendues à des tiers.

1. Responsable du traitement

Culture Connect 2026 - CVLN
Fort-de-France, Martinique 97200
Email : cultureconnectorg@gmail.com

2. Données collectées

Nous collectons les données suivantes lors de votre inscription :

  • Données d'identification : nom, prénom, organisation, pays
  • Coordonnées : adresse email, numéro de téléphone
  • Données professionnelles : type de profil (artiste, label, institution, presse), biographie
  • Données de paiement : traitées de manière sécurisée par Stripe (nous ne stockons pas vos données bancaires)
  • Données techniques : adresse IP, type de navigateur, pages visitées (via cookies)

3. Finalités du traitement

Vos données sont utilisées pour :

  • Gérer votre demande d'accréditation
  • Vous contacter concernant l'événement
  • Afficher votre profil dans le catalogue des participants (si vous le souhaitez)
  • Traiter votre paiement
  • Améliorer notre site et nos services
  • Respecter nos obligations légales

4. Base légale du traitement

  • Exécution du contrat : traitement de votre accréditation
  • Consentement : envoi de communications marketing, affichage dans le catalogue
  • Intérêt légitime : amélioration de nos services, sécurité du site
  • Obligation légale : conservation des données de facturation

5. Destinataires des données

Vos données peuvent être partagées avec :

  • Notre équipe : pour la gestion des accréditations
  • Stripe : pour le traitement sécurisé des paiements
  • Notre hébergeur : pour le stockage sécurisé des données
  • Autorités compétentes : si la loi l'exige

Nous ne vendons jamais vos données à des tiers.

6. Durée de conservation

  • Données d'accréditation : 3 ans après l'événement
  • Données de facturation : 10 ans (obligation légale)
  • Cookies : maximum 13 mois

7. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger des données inexactes
  • Droit à l'effacement : demander la suppression de vos données
  • Droit à la portabilité : recevoir vos données dans un format structuré
  • Droit d'opposition : vous opposer au traitement de vos données
  • Droit de limitation : limiter le traitement de vos données

Pour exercer ces droits, contactez-nous à : cultureconnectorg@gmail.com

8. Sécurité des données

Nous mettons en œuvre des mesures techniques et organisationnelles appropriées pour protéger vos données contre tout accès non autorisé, modification, divulgation ou destruction :

  • Chiffrement SSL/TLS pour toutes les communications
  • Stockage sécurisé des données
  • Accès restreint aux données personnelles
  • Surveillance continue de la sécurité

9. Transferts internationaux

Vos données peuvent être transférées vers des pays hors de l'Union Européenne (notamment pour l'hébergement et les services de paiement). Ces transferts sont encadrés par des garanties appropriées (clauses contractuelles types, décision d'adéquation).

10. Réclamation

Si vous estimez que vos droits ne sont pas respectés, vous pouvez introduire une réclamation auprès de la CNIL : www.cnil.fr

11. Modifications

Cette politique de confidentialité peut être mise à jour. Nous vous informerons de tout changement significatif par email ou via une notification sur le site.

12. Contact

Pour toute question relative à cette politique :
Email : cultureconnectorg@gmail.com
