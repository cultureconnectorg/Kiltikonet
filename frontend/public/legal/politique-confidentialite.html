Politique de Confidentialité

La présente politique de confidentialité décrit la manière dont Factory Maker Studio (« nous », « notre », « nos ») collecte, utilise et protège les informations personnelles que vous nous fournissez lors de l'utilisation du site Culture Connect 2026.

1. Responsable du traitement

Factory Maker Studio
Fort-de-France, Martinique
Email : cultureconnectorg@gmail.com

2. Données collectées

Nous collectons les données suivantes lors de votre inscription :

  • Données d'identification : nom, prénom, email, téléphone
  • Données professionnelles : organisation, type de profil, biographie, numéro SIRET (optionnel)
  • Données de navigation : adresse IP, type de navigateur, pages visitées
  • Données de paiement : traitées de manière sécurisée par notre prestataire Stripe
  • Photo/Logo : image de profil pour votre accréditation

3. Finalités du traitement

Vos données sont utilisées pour :

  • Gérer votre demande d'accréditation à Culture Connect 2026
  • Traiter votre paiement de manière sécurisée
  • Générer votre badge d'accréditation
  • Vous envoyer des informations sur l'événement
  • Faciliter le networking entre participants (catalogue public)
  • Améliorer nos services et votre expérience utilisateur
  • Respecter nos obligations légales

4. Base légale du traitement

Le traitement de vos données repose sur :

  • L'exécution du contrat : pour traiter votre inscription et paiement
  • Votre consentement : pour l'affichage dans le catalogue public
  • L'intérêt légitime : pour améliorer nos services
  • L'obligation légale : pour la conservation des données de facturation

5. Destinataires des données

Vos données peuvent être partagées avec :

  • Stripe : pour le traitement des paiements
  • Cloudinary : pour le stockage sécurisé des images
  • Resend : pour l'envoi des emails transactionnels
  • Nos partenaires institutionnels : dans le cadre de l'organisation de l'événement

Ces prestataires sont situés dans l'Union Européenne ou offrent des garanties conformes au RGPD.

6. Durée de conservation

Vos données sont conservées :

  • Données d'accréditation : 3 ans après l'événement
  • Données de facturation : 10 ans (obligation légale)
  • Données de navigation : 13 mois maximum
  • Cookies : selon votre choix de consentement

7. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger des données inexactes
  • Droit à l'effacement : demander la suppression de vos données
  • Droit à la limitation : restreindre le traitement
  • Droit à la portabilité : recevoir vos données dans un format structuré
  • Droit d'opposition : vous opposer au traitement
  • Droit de retrait du consentement : à tout moment

Pour exercer ces droits, contactez-nous à : cultureconnectorg@gmail.com

Vous pouvez également introduire une réclamation auprès de la CNIL : www.cnil.fr

8. Sécurité des données

Nous mettons en œuvre des mesures techniques et organisationnelles appropriées pour protéger vos données contre la destruction, la perte, l'altération, l'accès non autorisé :

  • Chiffrement SSL/TLS pour toutes les communications
  • Stockage sécurisé des données sensibles
  • Accès restreint aux données personnelles
  • Surveillance et audit régulier de nos systèmes

9. Transferts internationaux

Certains de nos prestataires peuvent être situés hors de l'Union Européenne. Dans ce cas, nous nous assurons que des garanties appropriées sont en place (clauses contractuelles types, certification Privacy Shield, etc.).

10. Modification de la politique

Nous nous réservons le droit de modifier cette politique de confidentialité à tout moment. Toute modification sera publiée sur cette page avec une nouvelle date de mise à jour.

11. Contact

Pour toute question concernant cette politique ou vos données personnelles :
